What it does for you

Your files, found. Your business, kept.

NOBAD Find reads your own files on your own PC and answers plain questions about them. It works offline and keeps everything it learns on this PC.

01 / Find it

By name, by words, by meaning.

Remember a word from inside, or only what it was about? Either is enough.

  • The words inside. Documents, PDFs, Office and ODF files, EPUB, code, notes and e-mail files (.eml, .mbox).
  • Photos by what's in them. Optional local models find files by meaning and photos by what they show.
02 / Ask plainly

Say it the way you'd say it.

Type a question in plain words, or narrow things down with the filter bar.

  • Plain-language questions. "rent pdf from last week", "photos on my usb stick", "newest".
  • "Here". Press Win+Shift+F in File Explorer and "here" means that folder.
03 / Keep it private

Nothing leaves your PC.

No account, no telemetry, and an index nobody else can read.

  • Encrypted index. What NOBAD Find learns about your files is encrypted, with a key protected by Windows.
  • Never admin. It runs as your normal account and keeps out of other people's files.

Privacy and security

8 features
  • Nothing leaves your PCNo account, no cloud, no telemetry.
  • Encrypted indexA SQLCipher database whose random key is protected by Windows DPAPI for your account on this PC.
  • Runs as you, never as adminIt refuses to start elevated. Only the Windows Search switch and the optional turbo index ask Windows, each through a helper that accepts fixed words.
  • Secrets stay unreadKey files, password stores, browser data, .ssh, wallets: off by default, and only their names even when you switch them on. Other people’s profiles are always out.
  • Your exclusionsAdd folders to Never search; Forget removes a result and keeps it out.
  • Files are untrustedZip-bomb checks, XML without external entities, size limits, separate low-priority readers, Windows’ own image decoders. Nothing is ever run.
  • Search history you controlOnly what you type in NOBAD Find, at most 200, inside the encrypted index. Turn it off or clear it any time.
  • Verified downloads onlyIts only connections: the optional model downloads from Hugging Face (pinned, checked by SHA-256) and the update check on GitHub, which you can turn off.

Windows

5 features

How it works

Three steps, no setup to speak of.

Install it for your account, press the hotkey, and switch on the extras only if you want them.

  1. 01

    Install

    A per-user installer: no admin prompt. It isn't code-signed yet, so Windows SmartScreen warns; choose More info → Run anyway.

  2. 02

    Press Win+Shift+F

    Type a name, a word from inside, or a question. Previews in the results show you which file is the one.

  3. 03

    Add what you want

    Meaning and photo search, USB and network drives, and using it instead of Windows Search. Each is off until you allow it.

FAQ

Questions, answered.

Still stuck? Support has the rest.

Does anything leave my PC?

No. There's no account and no telemetry. The only internet connections are the optional model downloads from Hugging Face, pinned and checked by SHA-256 and each off until you allow it, and the daily update check on GitHub, which sends nothing about you and can be turned off.

Do I need the models?

No. Names, the words inside and OCR work without them. Search by meaning needs a one-time model download (from 23 MB); photos by what's in them need 211 or 393 MB, also once.

Why doesn't it need administrator rights?

It only searches your own files, so it installs for your account and runs as your normal account, never as admin.

Can other people on this PC see my index?

The index is encrypted with a key Windows protects for your account (DPAPI). NOBAD Find never indexes other people's profiles.

Can it replace Windows Search?

Yes, with one click. Windows asks you once, and one click back restores Windows Search.

Why does Windows warn when I install it?

The installer isn't code-signed yet, so SmartScreen may say "Windows protected your PC". Check the SHA-256 in the download section, then choose More info → Run anyway.

How do I update it?

Settings → About → Updates. It checks once a day (or press Check now), and Install downloads the new version, checks it and installs it; your index and settings are kept. From 0.9.2 on this works without any manual step.

Which computers does it run on?

Windows 10 and Windows 11.
